# Expense Tracker App

Aplikasi pencatatan pemasukan dan pengeluaran untuk submission kelas **Belajar Membuat Front-End Web untuk Pemula** di Dicoding.

## Fitur Utama

- Menambahkan transaksi pemasukan dan pengeluaran.
- Menampilkan daftar transaksi.
- Menghitung total pemasukan, total pengeluaran, dan saldo.
- Memfilter transaksi berdasarkan kategori atau jenis transaksi.
- Menghapus transaksi.
- Menyimpan data transaksi secara lokal di browser.
- Antarmuka responsif untuk desktop dan perangkat mobile.

## Teknologi

- HTML5
- CSS3
- JavaScript
- Web Storage / Local Storage

## Struktur Project

```text
.
├── index.html
├── style.css
├── main.js
├── README.md
└── submission-rubric.md
```

## Menjalankan Aplikasi

1. Clone repository ini.
2. Buka folder project.
3. Jalankan `index.html` menggunakan browser.

Tidak diperlukan proses instalasi package atau build karena project menggunakan HTML, CSS, dan JavaScript murni.
